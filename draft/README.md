## 정리 원칙

이번 정리에서는 같은 기준을 가장 높은 적절한 문서에 한 번만 두고 하위 문서는 인용하도록 했다. 설명·예시·검토 메모는 규범 조문에서 제거했으며, 목록은 계산·기록에 필요한 경우만 남겼다. 회칙 44개 조와 세칙·운영방침의 기존 조 번호는 유지하여 인용 안정성을 확보했다.

다음 핵심 통제는 축약 뒤에도 유지된다.

- 회원권·등록·OB 접근, 임원 권한·직무대행·인계, 총회·선거와 이해충돌
- 신고·보호·징계·재검토, 선거관리자·검증자와 특별이의
- 수입 분리, 적자·차입·보증·담보 금지, 계약·후원·세무분류, 독립 재정점검
- 공동재원 물품, 프로젝트·지식재산, 조직 계정·백업·서비스 종료와 개인 이전
- 개인정보·인증정보 사고, 고위험 행사, 예비 공식 채널과 해산 청산

## 유지한 주요 금액

컴퓨터 관련 SIG는 학기당 50,000원, SIG·PIG 회식비는 참석 회원 1인당 10,000원, 기초 SIG장 장려금은 SIG당 150,000원이다. 대회 지원은 참가 회원 1인당 10,000원이며 전원 회원이고 공식 숙박이 필요하면 총 20,000원이다. 회계 단독 승인 한도 초안은 건별 300,000원이고 가예산은 30일간 총 500,000원이다.

회비는 오입금·중복납부를 전액 환불한다. 탈퇴와 환불 신청이 개강총회의 실제 시작 전이면 전액 환불하고, 시작 후에는 환불하지 않는다.

## 채택 전 확인

- 실제 계좌 구조·지급 승인자, 300,000원 한도와 학기말 점검범위
- 세무단체 승인서·고유번호증의 명칭·대표자·소재지·구성원
- 학교·총동아리연합회의 최신 등록·회계·행사·공간·개인정보 기준

총회 7일 전 회칙·세칙과 변경기록을 공개하고 총회에서 함께 의결한다. 이후 임원회의가 위임된 운영방침을 의결·공개하며, 확정 전문·개정이력·서식·행정대장을 정비한다.
