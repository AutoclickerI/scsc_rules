## 주요 금액

컴퓨터 관련 SIG는 학기당 50,000원, SIG·PIG 회식비는 참석 회원 1인당 10,000원, 기초 SIG장 장려금은 SIG당 150,000원이다. 대회 지원은 참가 회원 1인당 10,000원이며 전원 회원이고 공식 숙박이 필요하면 총 20,000원이다. 회계 단독 승인 한도는 건별 300,000원이고 가예산은 학기 중 한 차례, 30일간 학기 누계 500,000원이다.

회비는 오입금·중복납부를 전액 환불한다. 탈퇴와 환불 신청이 공고한 개강총회 예정 시작 시각과 적법하게 성립한 실제 시작 시각 중 늦은 시각 전이면 전액 환불한다.
