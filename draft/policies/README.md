# SCSC 위임 운영방침 초안

상위 규정이 위임한 범위에서 임원회의가 의결·공개한 뒤 시행한다.

| 운영방침 | 근거 | 범위 |
|---|---|---|
| P1 회원 등록·OB 접근 | 「SCSC 회칙」 제7조부터 제9조까지 | 등록 확인, OB 승인·접근 |
| P2 학기 회비 | 「SCSC 회칙」 제16조·제30조, 「SCSC 지원금 및 재정집행 세칙」 제37조 | 회비 공고·납부·환불·기록 |
| P3 SIG·대회 | 「SCSC 회칙」 제34조, 「SCSC 지원금 및 재정집행 세칙」 제33조·제37조 | SIG 분류, 신청수단·일정, 간소심사 대회 |

운영방침은 상위 규정의 권리·의무·제재·금액·의결권한을 바꿀 수 없다. 임원회의는 전문·시행일·변경이력을 시행 전에 공개하고, 사람·계좌·인증정보·신청자료 등 변경되거나 제한된 정보는 별도 행정기록으로 관리한다.
