## 3. 공통 제정·관리 원칙

1. 운영방침은 상위 회칙·세칙이 위임한 사항만 정한다.
2. 임원회의는 운영방침의 제정·개정·폐지를 의결하고 시행 전에 전문·시행일·변경이력을 공개한다.
3. 회원의 권리·의무에 영향을 주는 변경은 적용 전에 합리적인 확인기간을 둔다.
4. 현재 사람, 계좌, 인증정보, 신청자 명단과 원본 증빙은 공개 운영방침과 분리한 행정기록으로 관리한다.
5. 학기별 금액·기한·도구·담당자는 상위 규정이 요구하는 공고에 기록하며 운영방침 본문에 영구 고정하지 않는다.
