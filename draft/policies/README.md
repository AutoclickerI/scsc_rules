# SCSC 운영방침 초안

임원회의가 상위 규정의 범위에서 의결·공개한 뒤 시행한다. 회원발의가 있으면 총회가 재검토한다.

| 운영방침 | 근거 | 범위 |
|---|---|---|
| P1 회원 등록·OB 접근 | 「SCSC 회칙」 제6조·제7조 | 본회 학기등록 확인, OB 등록·접근 |
| P2 학기 회비 | 「SCSC 회칙」 제12조·제21조 | 회비 공고·납부·환불·기록 |
| P3 SIG·대회 | 「SCSC 회칙」 제25조·제26조, 「SCSC 지원금 및 재정집행 세칙」 제33조·제37조 | SIG·PIG 분류, 신청수단·일정, 행사 안전 행정, 간소심사 대회 |
| P4 개인정보 처리 | 「SCSC 회칙」 제5조 | 처리업무·보유·제공·위탁·파기·권리행사·사고대응 |

임원회의는 운영방침의 전문·시행일·변경이력을 시행 전에 공개하고, 「SCSC 회칙」 제16조제5항의 7일 재검토 기간을 지킨다. 사람·계좌·인증정보·신청자료 등 변경되거나 제한된 정보는 별도 행정기록으로 관리한다.
