# SCSC 운영방침 초안

임원회의는 상위 규정의 범위에서 운영방침을 의결·공개한다. 회원발의가 있으면 총회가 재검토한다.

| 운영방침 | 근거 | 범위 |
|---|---|---|
| P1 회원 등록·OB 접근 | 「SCSC 회칙」 제6조·제7조 | 학기등록, OB 등록·접근 |
| P2 학기 회비 | 「SCSC 회칙」 제12조·제21조 | 회비 공고·납부·환불·기록 |
| P3 SIG·대회 | 「SCSC 회칙」 제25조·제26조, 「SCSC 지원금 및 재정집행 세칙」 | SIG·PIG 분류, 대회, 행사 안전 |
| P4 개인정보 처리 | 「SCSC 회칙」 제5조 | 수집·이용·제공·보존·권리행사·사고대응 |

임원회의는 전문·시행일·변경 이력을 시행 전에 공개하고 「SCSC 회칙」 제16조제3항의 7일 재검토 기간을 지킨다. 사람·계좌·인증정보·신청자료 등 변동되거나 제한된 정보는 행정기록으로 관리한다.
